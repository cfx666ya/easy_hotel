# 易宿酒店预订平台（EasyStay Hotel Booking Platform）

## 项目简介

易宿酒店预订平台是一个面向现代旅游出行场景的综合服务系统，旨在为**酒店商户与终端用户**之间搭建高效、便捷的信息交互桥梁。

项目包含两大核心子系统：

- **用户端（移动端）**：提供酒店查询、筛选、浏览与预订流程
- **商户管理后台（PC端）**：提供酒店信息录入、编辑、审核与发布管理

通过良好的交互体验与数据管理能力，实现从**酒店展示 → 选择 → 预订 → 管理运营**的一体化流程。

## 项目功能一览

### 一、用户端（移动端）

#### 1.酒店查询页（首页）

- Banner广告轮播（点击跳转酒店详情）
- 城市定位 / 手动输入
- 关键词搜索
- 入住/离店日期选择（日历组件）
- 筛选条件（价格 / 星级）
- 快捷标签（亲子 / 豪华 / 免费停车等）

---

#### 2.酒店列表页

- 查询条件展示（城市、日期、间夜）
- 多维度筛选（价格 / 星级 / 标签）
- 酒店列表展示：
  - 酒店名称
  - 评分
  - 地址
  - 最低价格

- 支持**上滑加载（Infinite Scroll）**

---

#### 3.酒店详情页

- 顶部导航栏（返回）
- 酒店图片轮播
- 基础信息展示（星级 / 设施 / 地址）
- 日期 & 入住人数选择
- 房型价格列表（按价格排序）

---

### 二、酒店管理后台（PC端）

#### 1.登录 / 注册系统

- 支持角色：
  - 商户（录入/编辑酒店）
  - 管理员（审核/发布酒店）

- 注册选择角色
- 登录自动识别角色

---

#### 2.酒店信息管理（商户）

- 酒店信息录入
- 酒店信息编辑
- 数据实时更新至前端

数据维度包括：

- 酒店名称（中英文）
- 地址
- 星级
- 房型
- 价格
- 开业时间
- 可扩展：景点、交通、优惠信息等

---

#### 3.酒店审核管理（管理员）

- 审核状态：
  - 审核中
  - 通过
  - 不通过（带原因）

- 酒店发布 / 下线
- 下线支持恢复

## 本地运行

### 1.前端启动

```bash
cd client
npm install
npm run dev
```

### 2.后台管理系统

```bash
cd admin
npm install
npm run dev
```

### 3.后端服务

```bash
cd server
npm install
npm run start
```
